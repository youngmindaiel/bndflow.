# 학생 카운터

학생 수를 셀 때 쓰는 간단한 카운터 앱입니다. `index.html` 파일 하나로 동작하며
별도 설치·서버·인터넷 연결이 필요 없습니다.

## 사용법

- **＋ / −** : 카운터 값을 증감 단위(기본 1)만큼 올리고 내립니다.
- **숫자를 탭** : 그 카운터를 선택하면 아래에 `- 10 / + 10` 빠른 버튼이 나타납니다.
- **이름을 탭** : 이름·현재 값·증감 단위·빠른 버튼 단위·최솟값·색상을 바꾸거나,
  순서를 옮기거나, 삭제합니다.
- **우측 하단 ＋** : 카운터를 새로 만듭니다.
- **☰ 설정** : 합계 표시, 진동 켬/끔, 모두 0으로 초기화, 결과 복사, 전체 삭제.
- **되돌리기** : 방금 한 증감·초기화·삭제를 되돌립니다(최근 50개).

값은 브라우저에 자동 저장되어 앱을 닫았다 열어도 그대로 유지됩니다.
최솟값이 0이므로 기본 설정에서는 음수로 내려가지 않습니다.

## 휴대폰에서 쓰기

1. 이 파일을 웹에 올리고(예: GitHub Pages) `.../counter/` 주소로 접속합니다.
2. 브라우저 메뉴에서 **홈 화면에 추가**를 누르면 앱처럼 전체 화면으로 실행됩니다.

파일을 그대로 폰에 저장해 열어도 동작하지만, 홈 화면 추가를 쓰려면 웹 주소가 필요합니다.

## PC에서 쓸 때

방향키 ↑ / ↓ 또는 `+` / `-` 로 선택된 카운터를 조작할 수 있습니다.

## 데이터 저장 위치

브라우저의 `localStorage`(키: `student-counter.v1`)에만 저장됩니다.
외부로 전송되지 않으며, 브라우저 데이터를 지우면 함께 사라집니다.
