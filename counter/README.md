# 학생 카운터

학생 수를 셀 때 쓰는 간단한 카운터 앱입니다. `index.html` 파일 하나로 동작하며
별도 설치·서버·인터넷 연결이 필요 없습니다.

## 사용법

- **＋ / −** : 카운터 값을 증감 단위(기본 1)만큼 올리고 내립니다.
- **숫자를 탭** : 그 카운터를 선택하면 아래에 `- 10 / + 10` 빠른 버튼이 나타납니다.
- **이름을 탭** : 이름·현재 값·증감 단위·빠른 버튼 단위·최솟값·색상을 바꾸거나,
  순서를 옮기거나, 삭제합니다.
- **우측 하단 ＋** : 카운터를 새로 만듭니다.
- **☰ 설정** : 합계 표시, 진동 켬/끔, 모두 0으로 초기화, 결과 복사, 전체 삭제.
- **되돌리기** : 방금 한 증감·초기화·삭제를 되돌립니다(최근 50개).

값은 브라우저에 자동 저장되어 앱을 닫았다 열어도 그대로 유지됩니다.
최솟값이 0이므로 기본 설정에서는 음수로 내려가지 않습니다.

## 휴대폰 바탕화면에 넣기

웹 주소로 한 번 연 뒤 "홈 화면에 추가"를 하면 전용 아이콘이 생기고,
주소창 없는 전체 화면으로 열리며, 비행기 모드에서도 실행됩니다.

**아이폰 (Safari)**
1. Safari로 앱 주소를 엽니다. (Chrome 말고 Safari여야 합니다)
2. 아래 가운데 **공유** 버튼(□에 화살표)을 누릅니다.
3. 목록을 내려 **홈 화면에 추가** → 오른쪽 위 **추가**.

**안드로이드 (Chrome)**
1. Chrome으로 앱 주소를 엽니다.
2. 주소창에 **앱 설치** 버튼이 뜨면 누릅니다.
3. 안 보이면 오른쪽 위 **⋮** → **홈 화면에 추가** → **설치**.

첫 방문 때 한 번만 인터넷이 필요하고, 그 뒤로는 오프라인에서도 열립니다.

## 이 폴더의 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 본체 (화면·동작·저장 전부) |
| `manifest.webmanifest` | 앱 이름·아이콘·전체 화면 설정 |
| `sw.js` | 오프라인 실행용 서비스 워커 |
| `icon-192.png`, `icon-512.png` | 홈 화면/앱 목록 아이콘 |
| `apple-touch-icon.png` | 아이폰 홈 화면 아이콘 |

`index.html` 파일 하나만 따로 열어도 앱은 그대로 동작합니다.
나머지 파일은 홈 화면 추가와 오프라인 실행을 위한 것이며, 웹에 올려야 효과가 있습니다.

## PC에서 쓸 때

방향키 ↑ / ↓ 또는 `+` / `-` 로 선택된 카운터를 조작할 수 있습니다.

## 데이터 저장 위치

브라우저의 `localStorage`(키: `student-counter.v1`)에만 저장됩니다.
외부로 전송되지 않으며, 브라우저 데이터를 지우면 함께 사라집니다.
